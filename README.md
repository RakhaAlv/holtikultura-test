# 📖 Tentang SIMERAH

**SIMERAH (Sistem Informasi Monitoring dan Evaluasi Realisasi Hortikultura)** merupakan aplikasi berbasis web yang dikembangkan untuk mendukung proses pengelolaan data target dan realisasi bantuan komoditas hortikultura secara terintegrasi.

Sistem ini menyediakan dashboard interaktif untuk memantau perkembangan target dan realisasi bantuan berdasarkan komoditas, wilayah, serta tahun sehingga mempermudah proses monitoring, evaluasi, dan pelaporan.
